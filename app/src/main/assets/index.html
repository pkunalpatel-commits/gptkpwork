Feed and data notes

This build calls Dhan v2 expiry-list, option-chain and intraday candle endpoints, and subscribes to the selected contract through the Dhan v2 WebSocket quote feed. If authentication, contract mapping, or packet parsing fails, the status will show the error. Verify live values against Dhan's own platform before relying on them.
